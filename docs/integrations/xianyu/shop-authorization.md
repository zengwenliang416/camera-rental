# 闲管家店铺授权

## 目标

将闲管家应用、店铺授权和内部租赁店铺分开建模，支持一个应用授权多个店铺。
当前接口已于 `2026-07-23` 根据官方 Markdown 核对。

## 当前接口

```text
POST /api/open/user/authorize/list
body: {}
```

查询参数和签名使用
[认证与签名](authentication.md)中的统一契约。响应为：

```text
code
msg
data.list[]
```

## 建议数据对象

| 对象 | 关键字段 |
| --- | --- |
| 应用 | 内部应用 ID、AppKey、加密 AppSecret、接口地址、Webhook、启用和写操作状态 |
| 店铺授权 | `authorize_id`、`user_identity`、会员名 / 昵称、店铺名称、授权状态和有效期 |
| 同步游标 | 店铺授权 ID、同步类型、安全游标、最后成功时间 |
| 回调记录 | 幂等键、原始请求摘要、处理状态、重试次数 |

`AppSecret` 不得写入店铺记录、接口响应、普通日志或测试 Fixture。

应用配置由管理端按租户维护。店铺授权同步和所有后续调用必须从应用记录动态读取
凭证，不读取进程级商家凭证。

## 授权生命周期

1. 查询店铺和授权状态。
2. 保存授权有效期、套餐 / 类型和最近检查时间。
3. 同步订单或执行写操作前再次校验授权。
4. 授权失效时停止该店铺写操作并标记同步异常。
5. 保留历史订单、原始数据和设备排期，不删除历史业务数据。

## 当前字段基线

| 外部字段 | 用途 | 处理规则 |
| --- | --- | --- |
| `authorize_id` | 店铺授权 ID | 使用 64 位整数；在应用范围内建立唯一约束 |
| `authorize_expires` | 授权过期时间 | 保存原始秒时间戳；与 `valid_end_time` 同时保留 |
| `user_identity` | 稳定闲鱼会员标识 | 作为主要外部身份；不要使用已废弃的 `user_id` |
| `user_name` | 闲鱼会员名 | 可变化，只用于展示和辅助关联 |
| `user_nick` | 闲鱼昵称 | 展示字段 |
| `shop_name` | 店铺名称 | 展示字段 |
| `service_support` | 已开通服务项 | 保存原始逗号分隔值并标准化为集合 |
| `is_deposit_enough` | 服务保证金状态 | 用于授权健康提示，不替代接口调用权限 |
| `is_pro` / `is_trial` | 套餐状态 | 保存用于诊断 |
| `is_valid` | 是否有效订购中 | 为 `false` 时停止该店铺同步和所有写操作 |
| `valid_end_time` | 订购有效结束时间 | 保存原始秒时间戳；接口称同时订购时返回最长有效期 |
| `item_biz_types` | 准入业务类型 | 保存原始逗号分隔值并标准化 |

官方未提供完整“授权失效错误码”清单。实现必须同时处理列表状态失效和目标接口
返回的非零 `code`，并保存脱敏错误分类。

## 保证金健康状态

店铺同步按官方 `is_deposit_enough` 字段生成内部健康状态：

| 外部值 | 内部值 | 处理规则 |
| --- | --- | --- |
| `true` | `HEALTHY` | 保存到店铺健康状态，不生成告警 |
| `false` | `DEPOSIT_INSUFFICIENT` | 保存到店铺健康状态，并刷新一条店铺级 `GUARANTEE_HEALTH` 告警 |
| 缺失或无法识别 | `UNKNOWN` | 保存未知状态，不静默推断、不误报 |

保证金健康告警只提示运营处理，不代表授权必然失效，也不触发任何闲管家写操作。

## 测试

- 多店铺隔离。
- 授权失效停止任务。
- 授权恢复后从安全游标继续。
- 同一外部店铺不能绑定到错误应用。
- `user_name` 变化时不创建新店铺。
- 已废弃 `user_id` 缺失时仍可使用 `user_identity`。
- `is_deposit_enough=false` 时保存 `DEPOSIT_INSUFFICIENT` 并刷新去重告警。
