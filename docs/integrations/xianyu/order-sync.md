# 闲管家订单同步

## 同步策略

采用“订单推送 + 定时增量同步 + 订单详情补拉”：

1. 保存未经业务处理的原始推送。
2. 使用 `channel + application_id + external_order_no` 幂等。
3. 查询订单详情并保存原始响应。
4. 转换为内部租赁订单。
5. 解析 `seller_remark` 中的租期。
6. 触发排期计算或进入人工复核。
7. 使用安全游标补偿推送遗漏和状态变化。

## 分页边界

- 固定本次同步结束时间。
- 保存最后更新时间和稳定的并列游标。
- 处理相同更新时间的多条记录。
- 记录服务端数量、接收数量、去重数量和失败数量。
- 接近接口上限时拆分时间区间。
- 失败时从安全游标恢复，不从不确定位置继续。

## 关键字段

| 外部字段 | 内部用途 | 规则 |
| --- | --- | --- |
| `order_no` | 外部订单号 | 作为幂等键的一部分 |
| `authorize_id` | 店铺授权 | 同步前校验授权 |
| `seller_remark` | 日期解析原文 | 原文必须保留 |
| `total_amount` | 下单金额 | 不覆盖实付金额 |
| `pay_amount` | 总租金收入 | 进入内部系统转整数分 |
| `refund_amount` | 退款统计 | 与租金、押金、赔偿分开 |
| `express_fee` | 运费 | 按官方单位转换 |

金额单位、时间字段和状态枚举必须以目标接口 Markdown 为准。

## 备注解析

- 明确 `#租期7.25-7.27#` 时优先使用明确租期。
- 只有收货和发回时，收货次日开始计租，发回当天计租。
- 发货日期不参与计租天数。
- 缺少年份时结合订单时间推断。
- 日期冲突或字段不足时进入人工复核。
- 原始备注、解析版本、结果和错误原因一起保存。
