Processing pipeline

完整快照处理链路

供应商 SDK 只负责转换输入，核心领域只处理统一后的轨迹事件。

01
规范化字段 清理空格、统一状态、解析业务时间。
02
事件指纹 对规范字段生成稳定 SHA-256 fingerprint。
03
快照哈希 确定性排序后计算完整 snapshot hash。
04
版本决策 重复快照忽略，历史修正推进新版本。
05
当前摘要 选取最新状态，并应用终态防回退规则。
