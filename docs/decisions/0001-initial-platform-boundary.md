# ADR-0001 初始平台边界

- 状态：已接受
- 日期：2026-07-22

## 决策

采用 ruoyi-vue-pro 单体后端作为业务底座，保留以下独立仓库：

```text
camera-rental-server
camera-rental-admin
camera-rental-uniapp
camera-rental-staff
camera-rental-web
```

租赁领域作为后端独立模块规划，客户端共享后端 API。PC 客户官网使用 Nuxt，客户移动端使用 uni-app，管理后台使用 Vue 3 + Element Plus。

## 原因

- 当前已有后端、管理后台、客户商城端和员工移动端代码基线。
- 权限、支付、会员、商城和 ERP 能力可以按需复用。
- 单体架构更适合早期保持事务边界和部署简单。
- 租赁订单、设备实例和排期与普通商城订单的生命周期不同，必须保持领域边界。

## 约束

- 不把设备实例排期压缩成 SKU 库存数量。
- 不在各客户端复制权威金额、库存或排期算法。
- 不在当前阶段切换微服务。
- 不在没有官方接口文档确认的情况下实现闲管家写操作。

## 后续触发条件

以下工作开始前应新增或更新决策记录：

- 启用后端可选模块并改变根 `pom.xml`
- 创建 `yudao-module-rental`
- 新增数据库迁移
- 引入支付、实名、物流或第三方回调
- 改变订单状态或排期边界
- 将某个外部渠道作为写入来源
