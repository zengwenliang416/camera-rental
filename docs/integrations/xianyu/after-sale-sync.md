# 闲管家售后同步

## 范围

普通订单状态和售后订单状态分别同步。首期只读查询售后列表、详情和拒绝原因；
同意退款、拒绝退款属于写操作，默认禁用。

## 建议保存字段

- 售后单号。
- 关联外部订单号。
- 售后状态。
- 退款金额。
- 申请原因和拒绝原因。
- 平台更新时间。
- 原始售后 JSON 和哈希。
- 最近同步时间、转换版本和异常原因。

押金退还、租金退款和设备赔偿必须使用不同内部业务类型。

## 人工边界

自动同意或拒绝退款默认关闭。未来如需自动决策，必须单独设计金额上限、
允许状态、人工审批、幂等、审计和补救流程。

## 待补官方接口记录

## 测试

- 售后与普通订单状态隔离。
- 退款金额不覆盖实付金额。
- 重复售后推送幂等。
- 写操作授权缺失时拒绝执行。
