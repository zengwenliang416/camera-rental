# 验证与交付

本文件由 [根 AGENTS](../../AGENTS.md) 按任务引用。先检查当前清单和脚本内容，
在目标应用目录执行命令；根目录没有统一前端 `package.json`。
下表是命令入口，不是要求每次全量执行，也不是历史通过记录。

## 命令入口

| 应用 | 当前检查入口 | 注意事项 |
| --- | --- | --- |
| server | `mvn -pl yudao-module-rental/yudao-module-rental-biz -am test` | 从 server 目录运行，覆盖 Biz 及依赖；若有 `mvnw` 则优先同参数 Wrapper |
| admin | `pnpm ts:check`、`pnpm test:schedule`、`pnpm test:return-registration`、`pnpm test:rental-configuration` | 运行相关测试；构建按目标环境选 `pnpm build:local` 等真实脚本 |
| schedule-center | `pnpm lint`、`pnpm test`、`pnpm build` | `lint` 实际仅执行 `tsc --noEmit`，不能报告为 ESLint 通过 |
| staff | `pnpm type-check`、`pnpm build:h5`、`pnpm build:mp-weixin` | 跨端共享逻辑至少验证 H5 与微信小程序；涉及 App 能力补对应验证 |
| uniapp | 当前没有 H5/小程序构建 scripts | 按实际可用 HBuilderX 工具链验证两端；缺少工具时报告阻塞，不编造 `pnpm build:*` |
| web | `bun run test`、`bun run build`、`bun run test:e2e` | E2E 需匹配配置、浏览器和测试服务；SSR 构建不等于浏览器用例通过 |

后端不要仅选聚合 POM 后就假定 Biz 测试运行：检查 reactor 列表、测试数量、
Surefire 报告和 skipped 项；`-DskipTests` 的构建只能报告为编译/打包。
指定 `-Dtest=...` 做窄范围测试时，核对依赖模块的测试筛选行为，避免误把零用例当成功。

admin 的 `lint:eslint`、`lint:style`、`lint:format` 带修复/写入，检查使用对应
`:check` 脚本或工具对目标文件的只读选项。uniapp 的 `prettier` 脚本也会写入。
先做目标范围检查，不为处理无关历史告警而全仓格式化。

## 验证强度按影响选择

1. 修复先复现失败或建立可观察基线；纯规则先跑相关单测。
2. 运行受影响模块的类型检查/编译；接口变更验证请求、响应及错误语义。
3. 页面行为变更验证目标页面的真实交互和状态；跨端代码验证受影响平台构建。
4. 共享能力变更扩展到实际调用方，跨应用契约变更检查全部受影响客户端。
5. 最后审查 diff、测试覆盖及未验证范围；通过后不无理由重复全量检查。

| 改动 | 必须关注的直接行为与反例 |
| --- | --- |
| 排期/分配 | 半开区间边界、相邻/重叠、空窗口并发、重复请求、取消和续租影响 |
| 金额/日期 | 分币守恒、跨月/跨年/闰年、退款独立统计、时区与缺失日期 |
| 权限/租户 | 未登录、无权限、跨租户/越权 ID、切换身份后缓存隔离 |
| 同步/回调 | 分页固定边界、同更新时间、幂等、重试、验签失败、备注解析失败 |
| 履约重评 | 普通 READY 门槛、受控例外、已出库/回仓事实保护、失败事务回滚 |
| UI/共享状态 | 加载/空/错/无权限、重复提交、过期响应覆盖、卸载清理、相关消费者回归 |

涉及数据库锁和事务的正确性不能仅靠 Mock 单测证明；有条件时执行真实测试数据库的
并发/回滚验证，无法执行时明确证据缺口。第三方测试默认脱敏 Fixture/Mock；
真实接口需显式开启且默认只读，普通 CI 不调用真实店铺。

文档、注释和低影响可逆改动检查链接、命令依据、格式与内容一致性即可，
不增加复述实现的永久测试，也不为了改 AGENTS 启动整套业务服务。

## 完成报告

- 修改的应用、文件、用户可见行为与复用点。
- 实际执行的命令、工作目录、结果；失败项说明是否由本次改动引入。
- 未执行检查及原因，数据库迁移/配置/接口兼容影响和需要人工确认的假设。
- 明确区分实现、编译、单测、联调、页面验收、部署与用户验收。
  最终 diff 仅包含授权改动，无关工作区修改保持原状。
