# 客户退回登记

公开入口为 `/return`，用于客户在设备寄回或送回前登记本次退回信息。

## 简化登记字段

- `orderNo`：闲鱼订单号，可不填。填写时必须与机器编码对应的订单一致。
- `senderMobile`：发件人手机号，必填，保存完整的 11 位中国大陆手机号。
- `machineCode`：机器编码，必填，用于准确定位订单设备或进入人工复核。
- `returnMethod`：归还方式，支持 `EXPRESS`、`ERRAND`、`SELF_DELIVERY`。
- `waybillNo`：仅快递寄回时必填。
- `errandPlatformName`：仅跑腿送回时必填，例如闪送、达达或 UU 跑腿。
- `attachmentIds`：退回照片，可不填。

发件人手机号只记录本次退回的联系信息，不参与闲鱼订单收件手机号匹配。订单号为空时，系统通过机器编码查找唯一候选订单；无法安全匹配时保存登记并进入人工复核，不静默猜测。

## 归还方式

- 快递寄回：保存快递单号，承运名称暂记为“待仓库识别”。
- 跑腿送回：保存跑腿平台名称作为承运名称，不保存跑腿单号。
- 本人送回：后端固定保存承运名称“本人送回”，不要求物流单号。

## 数据与权限

`rental_return_registration.sender_mobile` 保存发件人手机号。公开接口和普通日志不得输出该手机号；管理端仅在具有退回登记查询权限的详情页展示。
