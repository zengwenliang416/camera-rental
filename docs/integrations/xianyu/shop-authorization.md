# 闲管家店铺授权

## 目标

将闲管家应用、店铺授权和内部租赁店铺分开建模，支持一个应用授权多个店铺。
具体查询接口和字段含义以当前官方目标接口文档为准。

## 建议数据对象

| 对象 | 关键字段 |
| --- | --- |
| 应用 | 内部应用 ID、AppKey、启用状态 |
| 店铺授权 | `authorize_id`、外部店铺标识、店铺名称、授权状态 |
| 同步游标 | 店铺授权 ID、同步类型、安全游标、最后成功时间 |
| 回调记录 | 幂等键、原始请求摘要、处理状态、重试次数 |

`AppSecret` 不得写入店铺记录、接口响应、普通日志或测试 Fixture。

## 授权生命周期

1. 查询店铺和授权状态。
2. 保存授权有效期、套餐 / 类型和最近检查时间。
3. 同步订单或执行写操作前再次校验授权。
4. 授权失效时停止该店铺写操作并标记同步异常。
5. 保留历史订单、原始数据和设备排期，不删除历史业务数据。

## 测试

- 多店铺隔离。
- 授权失效停止任务。
- 授权恢复后从安全游标继续。
- 同一外部店铺不能绑定到错误应用。
