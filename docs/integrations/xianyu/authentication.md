## 配置边界

- 商家凭证、接口地址、Webhook、真实写操作开关和同步参数统一在
  `camera-rental-admin` 的闲管家配置页按租户维护。
- 配置保存到 `xianyu_application`；`app_secret` 使用
  `EncryptTypeHandler` 加密落库，管理端响应只返回“是否已配置”，永不回显明文。
- 后端客户端每次调用都按当前租户重新读取持久化配置，不缓存进程级商家凭证。
- Webhook 根据请求中的 `appid` 跨租户解析唯一应用，验签成功后切换到对应租户
  处理事件。
- 真实写操作和定时同步默认关闭，必须由有权限的管理员显式开启。
- 闲管家集成配置仍归在“租赁运营”菜单下，但页面和配置更新接口仅允许
  `super_admin` 使用；普通员工不显示该菜单，也不能直接访问配置页。
- 员工核对、同步和发货所需的订单号、收货人、手机号、地址、卖家备注和物流单号
  按业务原值展示；AppKey、AppSecret、签名和 Token 等接入密钥始终不得回显。
- 定时任务 cron 在管理端“基础设施 -> 定时任务”维护；闲管家配置页只控制当前
  租户是否允许任务执行及同步窗口参数。
- 一个应用可以授权多个店铺，不能把店铺写死在应用配置中。
- 管理端响应不得返回 `AppSecret`。

服务端不提供闲管家商家业务配置的环境变量或 Spring 配置绑定兼容入口。数据库
字段加密主密钥属于通用基础设施配置，不属于闲管家商家配置。

## 当前请求契约

生产基础地址：

```text
https://open.goofish.pro
```

当前目标接口统一使用：

```text
POST {baseUrl}{path}?appid={appKey}&timestamp={epochSeconds}&sign={sign}
Content-Type: application/json
```

- `appid` 传开放平台提供的 AppKey。
- AppKey 在配置和 URL 构造中按字符串处理，不做数值运算。
- `timestamp` 使用 Unix 秒；目标接口说明其五分钟内有效。
- 即使 OpenAPI 将 `timestamp` 标为非必填，签名规则和示例都依赖该值，客户端
  必须始终发送。
- 请求体必须是 JSON 原文。无业务参数的接口发送并签名同一个空对象字符串
  `{}`，不能签名 `{}` 后发送空 body。
- 所有字段强校验，必须按官方字段类型传参。
- 外部订单号、退款单号以及返回前端的其他长标识统一按字符串处理，避免
  JavaScript 安全整数精度丢失。

## 签名算法

自研 / 第三方 ERP 模式：

```text
bodyMd5 = md5Hex(utf8(bodyString))
signSource = appKey + "," + bodyMd5 + "," + timestamp + "," + appSecret
sign = md5Hex(utf8(signSource))
```

商务对接模式会在时间戳和密钥之间增加 `sellerId`：

```text
appKey + "," + bodyMd5 + "," + timestamp + "," + sellerId + "," + appSecret
```

本项目默认按自研应用模式设计。若实际账号属于商务对接，必须单独确认后再启用
`seller_id`，不能自动猜测模式。

## 客户端职责

统一的闲管家客户端负责：

- 使用统一 JSON 配置完成一次最终序列化，保存同一个 `bodyString`。
- 调用前从当前租户的 `xianyu_application` 解析最新配置。
- 按官方规则生成认证信息。
- 使用签名时相同的 UTF-8 字节发送请求体，发送前不得格式化或重新序列化。
- 设置连接、读取和整体超时。
- 将网络、认证、限流、参数和服务端错误转换为内部异常。
- 对允许重试的临时失败执行有限次退避。

签名完成后不得再次修改或重新序列化参与签名的请求体。
