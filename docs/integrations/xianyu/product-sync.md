# 闲管家商品同步

## 领域边界

闲鱼商品、内部租赁 SKU 和具体设备实例是三个不同概念：

```text
内部设备和排期
    ↓
计算时间段可租数量
    ↓
生成渠道库存策略
    ↓
同步闲鱼商品库存
```

闲鱼商品库存不能直接代表某一台设备是否可用。

## 首期只读范围

- 类目、属性、商品列表、商品详情和规格查询。
- 商品与内部 SKU 的映射准备。
- 渠道库存计算结果的审计记录。

创建、编辑、库存修改、上下架和删除均为写操作，默认禁用。

## 建议映射

| 外部对象 | 内部对象 | 关系 |
| --- | --- | --- |
| 闲鱼商品 | 租赁商品 SKU | 渠道发布映射 |
| 闲鱼规格 | 租赁商品规格 | 规格映射 |
| 渠道库存 | 时间段可租数量 | 策略结果，不是设备实例 |
| 商品外部 ID | 渠道商品记录 | 需唯一约束 |

## 待补官方字段

| 项目 | 状态 |
| --- | --- |

| 商品列表分页 | 待从目标 Markdown 补录 |
| 详情和规格字段 | 待从目标 Markdown 补录 |
| 商品库存单位 | 待从目标 Markdown 补录 |

## 测试

- 商品与 SKU 映射幂等。
- 规格缺失和规格变化。
- 排期结果到渠道库存的边界值。
- 禁止在只读任务中触发商品写操作。
