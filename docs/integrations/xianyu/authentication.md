## 配置边界

```yaml
rental:
  xianyu:
    enabled: false
    base-url: https://open.goofish.pro
    app-key: ${XGJ_APP_KEY:}
    app-secret: ${XGJ_APP_SECRET:}
    webhook-base-url: ${XGJ_WEBHOOK_BASE_URL:}
```

- 示例只允许出现空占位符。
- `AppSecret` 只能在后端运行时注入。
- 一个应用可以授权多个店铺，不能把店铺写死在应用配置中。
- 管理端响应不得返回 `AppSecret`。

## 客户端职责

建议由统一的 `XgjClient` 负责：

- 固定请求体并完成最终序列化。
- 按官方规则生成认证信息。
- 设置连接、读取和整体超时。
- 将网络、认证、限流、参数和服务端错误转换为内部异常。
- 对允许重试的临时失败执行有限次退避。

签名完成后不得再次修改或重新序列化参与签名的请求体。
