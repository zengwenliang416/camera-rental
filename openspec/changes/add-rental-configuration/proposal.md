## Why

闲鱼订单当前混用了闲管家商品 ID 与闲鱼商品 ID，并把完整备注和设备型号映射作为
创建内部租赁订单的前置条件，导致大量已收款渠道订单停留在待转换或人工复核状态。
设备目录和渠道映射也缺少独立、可审计的配置入口，无法稳定支持一个商品对应多个型号。

## What Changes

- 新增“租赁配置”页面，集中维护设备目录、商品处理规则、精确型号映射和备注规范。
- 分离保存闲管家商品/SKU ID 与闲鱼 item/SKU ID，禁止标识回退和文本猜测。
- 支持单型号商品按 `店铺 + item_id` 映射，多型号商品按同步 SKU 精确映射。
- 普通渠道订单详情落库后立即幂等创建内部订单，备注和型号后续增量补全。
- 增加可配置的 `CONFIG_SKIPPED` 商品规则和 29 个初始过滤商品。
- 增加备注更新、续租、早退、改期、换机和历史补建的履约保护策略。
- 将设备大类/型号维护入口从“租赁设备”迁移到“租赁配置”。

## Capabilities

### New Capabilities

- `rental-configuration`: 设备目录、渠道商品规则、单/多型号映射、备注规范和权限化管理。
- `xianyu-order-reconciliation`: 渠道标识标准化、即时内部建单、增量补全、过滤和历史重评。

### Modified Capabilities

None.

## Impact

- 后端：租赁模块的闲鱼商品/订单持久化、转换、映射、备注解析、排期保护和历史补建。
- 数据库：新增增量 migration、商品规则/备注历史及语义明确的标识和状态字段。
- 管理端：新增租赁配置页面、API、权限、菜单和中英文文案，精简租赁设备页。
- 外部接口：仅使用闲管家现有只读订单详情、商品详情和商品规格接口，不执行第三方写操作。
