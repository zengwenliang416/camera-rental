# 闲管家集成总览

## 目的

本目录描述相机租赁平台与闲管家开放平台的集成边界、数据流和实现准备。
具体接口参数、签名算法、状态枚举和错误码以当前官方文档为准。

- 本地来源说明：[source.md](source.md)
- 领域规则：[../../domain/xianyu-integration.md](../../domain/xianyu-integration.md)

## 能力范围

| 能力 | 首期边界 | 说明 |
| --- | --- | --- |
| 店铺授权 | 只读查询 | 应用与店铺授权分开建模 |
| 商品 | 只读查询 | 商品、规格和详情先建立映射 |
| 订单 | 只读同步 | 列表增量、详情补拉、幂等落库 |
| 售后 | 只读同步 | 退款动作默认人工处理 |
| 推送 | 接收和落原始数据 | 回调线程只做校验、落库和入队 |
| 写操作 | 默认禁用 | 必须经过明确授权和审计 |

## 后端边界

闲管家集成代码应位于租赁后端模块：

```text
yudao-module-rental-biz/src/main/java/.../module/rental/integration/xianyu/
```

业务 Service 只依赖内部接口，不直接构造签名、序列化请求或发送 HTTP。

## 数据流

```text
闲管家推送 / 增量查询
        ↓
原始数据保存与幂等判断
        ↓
订单详情补拉与字段标准化
        ↓
租赁订单转换 / 备注解析
        ↓
排期计算或人工复核
```

## 当前不做

- 不凭字段名猜测官方接口参数。
- 不把闲鱼渠道库存当作具体设备实例库存。
- 不自动发货、改价、上下架、删除商品或处理退款。
- 不在前端调用需要服务端密钥的接口。
