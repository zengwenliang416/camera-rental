# 员工作业流程修复（1.0.2）

## 页面行为

- 首页订单卡片与订单详情携带对象 ID 进入发货页。指定订单通过后端队列逐页精确匹配，不能匹配时展示错误，不自动换单。
- 发货页顺序为当前订单、设备核验、运单、最终确认。手工输入收起；重扫保留订单与其他字段，更换订单需要确认并清空旧扫描信息。
- 订单摘要和最终确认展示收件信息，仅保留在当前页面及非持久化草稿，不写入异常日志或 URL。
- 手工设备编号使用已有设备分页接口并精确匹配；签名永久码保持完整，由原解析接口验签，不退化成普通编号查询。
- 订单详情每次重新显示时刷新；列表保留已加载页和滚动容器，后台刷新失败时保留旧列表并标注错误。
- 分配候选刷新时重新校验已选设备和剩余数量，部分成功会保留成功反馈并刷新候选；检测返回时提示未提交内容。
- 设备排期请求失败明确显示未知；查看订单定位关联订单，完整排期按钮定位真实时间线。
- 回仓备注归属于当前设备；更换设备清空旧备注，重复扫描同一设备保留备注。
- 异常中心改为当前登录的操作记录；标记仅代表已查看，不表示业务问题已解决。支持返回关联订单/明细，网络错误显示处理说明。
- 字典缓存清理不再删除认证、租户或其他存储。主要作业页面统一浅色（1.0.3 恢复原红色主风格），移除未完整适配的深色切换。

## 现有业务边界

现有 `/rental/xianyu/order/ship` 一次绑定一台设备并完成渠道订单发货，不支持前端循环调用实现多设备整单发货。
手机显示订单设备总数，对多明细或多设备订单给出明确阻断说明，要求在管理后台处理；本次没有扩展后端发货事务契约。
设备最终许可、租户、型号、状态和排期由后端校验，页面状态不能代替业务校验。

## 验证

`node scripts/test-staff-workflow.mjs` 加载实际纯逻辑、API 及 Vue 页面脚本，以脱敏内存数据覆盖跨页选单、ID 不匹配、重扫与搜索不丢订单、设备精确查询、备注归属、候选刷新、详情回显刷新。
`node scripts/test-scanner.mjs` 继续覆盖扫码适配器与页面生命周期。
另执行类型检查、目标 ESLint、H5/微信小程序构建与 Android 独立打包。
没有向真实店铺提交测试发货，也没有提交真实分配或回仓检测。光学扫描和最终履约验收需要真机业务操作单独验证。

## 1.0.3 配色修正

恢复原主色 `#e10600` 和按下色 `#b80500`；启动时同步覆盖旧的持久化主题变量，避免仍显示 1.0.2 青绿按钮。发货页选中态使用同一主色变量，成功状态保持绿色，错误保持红色。流程、布局及品牌图标不变。

## 1.0.4 移动作业与主题

- “我的”和“应用设置”恢复深色开关；使用已有 Pinia 持久化保存选择，启动不再强制浅色。Wot 组件、业务页面、登录/账号页面、底栏和 Android 状态栏同时适配；主按钮保持品牌红色，深色下红色文字提高亮度以保证可读性。
- 对齐 Wot 2 的 `variant="plain"` 按钮契约，恢复次要按钮描边与筛选选中态的区分。
- 首页新增设备排期、今日作业、设备目录入口。复用现有排期工作台和设备分页 API，不复制库存或排期可用性规则。排期支持 14/30 天、日期窗口、设备关键词与扫码定位；占用结束按半开区间转换显示。
- 今日作业展示应发、计划回仓、占用超期核对及待检测；按北京时间分组。回仓计划采用包含检测的占用结束日，并核对分配是否仍为出库态，不将其描述为客户承诺归还日。当前接口没有日期聚合队列，每次操作仅核对 20 条并显示覆盖进度，未加载全部时不声称全量统计；后续可扩展服务端日期筛选。
- 设备目录支持编号/序列号关键词及精确型号筛选；各页按权限展示，不缓存客户联系人。
- 订单/设备详情提供显式复制，订单提供拨号入口；脱敏号码不能拨打。设置页通过公开版本摘要检查更新，只接受固定包名及版本化 HTTPS 下载路径，经用户确认打开浏览器安装。
- 新增 `node scripts/test-mobile-workbench.mjs` 与 `node scripts/test-staff-theme.mjs`，覆盖日期边界、更新来源、脱敏电话、过期请求、分批重试及实际 Pinia 主题重启恢复。

以上是实现契约；构建、独立 APK 安装、线上只读查询与真实履约操作分别验证。多设备发货限制保持不变。

## 1.0.5 跟随系统主题

- 外观选择改为“跟随系统 / 浅色模式 / 深色模式”，我的及设置共用同一个选择器。新安装及从旧版升级默认跟随系统；显式手动选择优先且持久化。
- App 启动读取系统主题，并通过 uni-app 的主题事件同步前台变化；回到前台重新读取，补偿后台错过的通知。监听仅在应用级注册一次，卸载时释放。
- Android PDA 上框架通知可能缺失，额外监听系统 CONFIGURATION_CHANGED 广播后重新读取系统主题；Android 13+ 使用不导出接收器，注销后忽略晚到回调。
- App/H5/微信小程序开启框架的 darkmode 支持；深浅色仍使用捷租达既有红色语义配色，Android 系统栏同步实际生效主题。
- 只保存用户选择，不把最后看到的系统主题当作长期偏好。与租赁业务日期无关，订单及排期继续使用 Asia/Shanghai。
- 主题测试覆盖旧缓存迁移、系统双向切换、手动覆盖、返回跟随系统、后台恢复、重启和取消监听。
